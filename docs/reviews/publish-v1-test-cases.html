v1.0.0 用户验收用例

目标：用户可以从 GitHub 安装 Skill，并在不破坏现有项目规则的前提下，根据业务诉求初始化治理文件。

覆盖结论：共 10 个高价值场景，覆盖安装、黄金流程、重复执行、已有文件保护、业务文档输入、边界、异常和跨平台命令。
ID类别用户操作预期结果优先级自动化
INS-01黄金流程通过 npx skills add 从公开仓库安装。发现并安装 repo-architecture-guard。高远端冒烟
INS-02黄金流程用完整参数初始化空项目。生成目标、状态、AGENTS 管理区块和代码地图，并输出清单。高单元+冒烟
INS-03保护在已有 AGENTS 规则的项目初始化。原有内容保持不变，只追加一个管理区块。高单元
INS-04重复执行连续运行初始化两次。管理区块保持一个，内容原位更新。高单元
INS-05保护项目已有 ProjectGoal 且未传强制参数。目标文件不被覆盖，结果标记 preserved。高单元
INS-06业务输入传入 UTF-8 业务诉求文档。业务原文和来源被保留，未知字段明确待确认。中单元
INS-07边界产品字段包含中文、多行内容和标点。生成的 Markdown 保持 UTF-8 且内容完整。中单元
INS-08错误传入不存在的业务文档。返回非零状态和明确错误，不产生误导性成功结论。高单元
INS-09可控跳过使用 --no-code-map。只初始化产品治理文档，不运行地图脚本。中单元
INS-10兼容性Windows PowerShell 与 macOS/Linux shell 执行 README 指令。使用同一 Python 脚本和相同产物结构。高CI+文档检查
