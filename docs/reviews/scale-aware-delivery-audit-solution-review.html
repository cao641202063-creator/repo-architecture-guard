规模化交付与审计

版本：scale-aware-delivery-audit · 状态：产品负责人已于 2026-08-03 确认

目标与决策记录

受影响角色：产品经理、主交付 Agent、独立审计 Agent 与人工审核人。

范围：由代码地图引导的全局理解、文档影响处置和有界交付审计。大型仓库获得基于证据的全局理解；每次代码改动都有文档影响处置；完整流程在人工审核前进行一次独立审计。

业务规则：代码地图是导航证据而非行为证明；每份相关文档都必须有处置；审计首轮只读，主 Agent 最多修订一轮。

假设：完整流程可获得独立 Agent 上下文。待决策项：无。非目标：全仓重复阅读、自动代替产品决策、递归式 Agent 互审或替代人工批准。

范围优先的理解过程

相关代码地图节点→范围假设→定向验证源码与测试→已验证的逻辑与影响切片

未知事实必须明确保留；代码地图用于导航，不能替代阅读已变更的源码。

交付审计过程

主 Agent：实现并验证→独立 Agent：只读审计→主 Agent：修订一轮→人工：最终确认

无法独立委派时，交付必须明确记录为自检，不能宣称进行了独立审计。
