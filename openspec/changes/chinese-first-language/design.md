## Context

当前 Skill 的规则和契约以英文为主，而产品经理审阅是核心使用场景。命令、路径、代码和机器字段必须保持稳定，不能被翻译破坏。

## Goals / Non-Goals

**Goals：** 将后续人类可读交付默认切换为简体中文，并将当前正在展示的方案确认页同步为中文。

**Non-Goals：** 批量改写历史归档、翻译代码/命令/路径，或改变任何运行时接口。

## Decisions

在 Skill、生成模板和产物契约中定义一次中文优先规则；其他规则引用该约定。技术字符串原样保留，历史证据仅在被当前变更影响时更新。

## Risks / Trade-offs

- 术语翻译可能降低可搜索性 → 首次出现时可保留英文术语或代码形式。
- 历史内容混合语言 → 不追溯改写，避免造成无意义的大型差异。
